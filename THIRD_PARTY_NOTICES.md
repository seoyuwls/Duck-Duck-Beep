# 제3자 라이선스 고지

## Phosphor Icons

앱의 아이콘(도감, 설정, 완료 체크, 뒤로 가기)은 [Phosphor Icons](https://phosphoricons.com)의 regular 스타일을 사용합니다.
공식 저장소(https://github.com/phosphor-icons/core)의 SVG를 안드로이드 벡터(`app/src/main/res/drawable/ph_*.xml`)로 옮긴 것입니다.

| 파일 | 아이콘 |
|---|---|
| `ph_book_bookmark.xml` | book-bookmark (도감) |
| `ph_gear.xml` | gear (설정) |
| `ph_arrows_clockwise.xml` | arrows-clockwise (닉네임 셔플) |
| `ph_check_circle.xml, ph_arrows_clockwise.xml` | check-circle (보내기 완료) |
| `ph_caret_left.xml` | caret-left (뒤로 가기) |
